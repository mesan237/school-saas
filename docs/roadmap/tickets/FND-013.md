# FND-013 — Each user keeps their own language (including after logout)

- **Branch:** feat/FND-013-user-locale (based on feat/FND-foundation)

## Decision (PO, 2026-10-23)

"Set it to its own language when logging out": after logout, a user keeps seeing the language they use, not the French default.

## Design

- `users.locale` (nullable, `fr|en`) stores the preference on the account, so it follows the user across devices.
- A `locale` cookie (encrypted, 1 year) remembers the language in the browser and **survives logout**. The session can't do this: logout invalidates it.
- Priority in `SetLocale`: signed-in user's saved preference → cookie → default `fr`. All values are allow-listed.
- While signed in, the cookie is synced to the user's preference, so the logged-out pages show their language.
- Switching (`POST /locale`) sets the cookie, and also saves to the account when signed in.

## Acceptance criteria

- [x] A guest's choice persists in the browser
- [x] A signed-in switch is saved on the account
- [x] The saved preference wins over a stale cookie
- [x] After logout, the login page shows the user's language
- [x] Tampered or invalid cookie and preference values fall back to `fr`
- [x] The migration is reversible
